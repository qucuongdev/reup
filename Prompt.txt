# ROLE
Bạn là Senior Full-stack Engineer + AI/Media Pipeline Engineer.

Nhiệm vụ: tạo một repo mới để xây dựng tool **Video Localizer** chạy local, dùng `pyVideoTrans` làm core dịch/lồng tiếng, sau đó bổ sung downloader và post-processing riêng.

Không viết lại những chức năng mà `pyVideoTrans`, `yt-dlp` hoặc `FFmpeg` đã làm tốt.

---

# OBJECTIVE

Xây dựng MVP có luồng:

```text
Video URL hoặc file local
→ Download nếu là URL
→ Dịch/lồng tiếng bằng pyVideoTrans
→ Chinese/English/... → Vietnamese
→ Subtitle
→ Resize/crop
→ Watermark tùy chọn
→ Generate thumbnail
→ Render video cuối
→ Lưu output + metadata
```

Mục tiêu cuối:

Người dùng nhập một URL video hoặc upload file local, chọn cấu hình, bấm Process và nhận được:

```text
final.mp4
thumbnail.jpg
subtitle.srt
metadata.json
```

---

# CORE PRINCIPLE

`pyVideoTrans` phải được xem như **external/core engine**, KHÔNG fork và sửa sâu source code của nó nếu chưa thật sự cần thiết.

Ưu tiên:

```text
our app
   ↓
adapter/service layer
   ↓
pyVideoTrans CLI/API
```

Thay vì:

```text
copy source pyVideoTrans
→ sửa trực tiếp khắp nơi
```

Mục tiêu là sau này có thể update pyVideoTrans mà không phá app.

# 4. pyVideoTrans adapter

Không copy toàn bộ logic của pyVideoTrans.

Tạo abstraction:

```python
class TranslationEngine:
    def process(input_video, config) -> TranslationResult:
        ...
```

Implementation:

```text
PyVideoTransEngine
```

Adapter chịu trách nhiệm:

- truyền input video
- source language
- target language
- ASR engine
- translation engine
- TTS engine
- output path
- capture logs
- capture exit code
- phát hiện lỗi

Mặc định MVP:

```text
source_language = zh-cn
target_language = vi
ASR = faster-whisper
TTS = Edge-TTS
```

Translation engine phải configurable qua `.env`.

Không hard-code API key trong source.

# 6. Post-processing

Tách thành module riêng, dùng FFmpeg.

Hỗ trợ:

```text
original
16:9
9:16
1:1
```

Resolution mặc định:

```text
16:9 → 1920x1080
9:16 → 1080x1920
1:1  → 1080x1080
```

Không được stretch video.

Dùng:

```text
scale + crop
```

hoặc:

```text
scale + pad
```

tùy config.

Tạo abstraction:

```python
class VideoProcessor:
    resize(...)
    crop(...)
    add_watermark(...)
    normalize_audio(...)
    burn_subtitle(...)
```

# 9. Thumbnail generator

Thumbnail là output riêng, không phải video frame overlay.

Flow:

```text
final video
→ extract representative frame
→ resize 1280x720
→ optional title overlay
→ optional branding
→ thumbnail.jpg
```

MVP chưa cần AI image generation.

Cho phép chọn:

```text
auto
timestamp
```

Nếu auto thì lấy frame khoảng 30% duration hoặc một chiến lược đơn giản, deterministic.
